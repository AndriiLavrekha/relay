# Agent Task Bridge v0.1.0

First public release of Agent Task Bridge.

## Included

- Local-first Task Capsule export and Result Capsule import.
- Repository drift detection and isolated Git worktree staging.
- Safe archive/path handling and secret-content checks.
- Local validation for supported Node.js projects.
- Self-contained Claude Code and Codex plugins.
- Public marketplace entries under `task-bridge@awesome-task-bridge`.
- Claude Code and Codex installation instructions pinned to the `v0.1.0` release.

## Requirements

- Node.js 22 or newer
- Git
- A Git repository for export/import
