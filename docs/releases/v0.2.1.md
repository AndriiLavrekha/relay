# Agent Task Bridge v0.2.1

Agent Task Bridge v0.2.1 makes worker reports visible in local review and separates host-owned gates from work the external worker can finish. Protocol `1.0` and schema `1.1` stay in place. Capsules from v0.2.0 remain readable.

## Included

- Durable `REPORT.md` storage at `.agent-task-bridge/tasks/<task-id>/imports/<import-id>/REPORT.md`, including failed, rejected, and interrupted imports.
- A 512 KB uncompressed limit for `REPORT.md` (`REPORT_TOO_LARGE`).
- Review parsing of Summary, Assumptions, Validation claims, Unresolved work, Findings, and Recommendations, with review text capped at 64 KB.
- High-confidence secret redaction in review JSON and terminal review output. The raw report stays in git-ignored bridge storage.
- Export-time context coverage warnings for omitted in-scope text files, `files.editable` paths outside `editable_scope`, and missing literal scope paths.
- Git-based candidate discovery so ignored files and known binary extensions are not reported as omissions.
- Negative scope patterns prefixed with `!`, with repeated `**` wildcards collapsed before matching.
- Optional `host_owned_steps` on delegation requests and task manifests. Omitted values use the three default host gates. An explicit empty array declares none.
- Acceptance status `deferred_to_host`, overall statuses `deferred_to_host` and `verified_with_deferred`, and review fields that keep host gates from triggering follow-up by themselves.
- Execution-boundary instructions in the Task Capsule, kickoff prompt, and Claude Code and Codex export/import skills.

## Compatibility

`atb_protocol` remains `1.0`. A task manifest without `host_owned_steps` does not reclassify keyword criteria. Explicit `[host]`, `[host-owned]`, `(host)`, and `host-owned:` tags still defer. Result capsules without `REPORT.md` import as before when the status does not require a report.

Coverage warnings never block export. The working tree and Git index are not modified by the check.

## Workflow

```text
node bin/agent-task-bridge.mjs export --delegation delegation.json --repo .
node bin/agent-task-bridge.mjs import result.zip --repo .
node bin/agent-task-bridge.mjs review <import-id> --repo .
```

Read `warnings` on the export result and the upload checklist before sending a capsule. After import, read `review.workerReport` and `# Deferred Host Steps` in the review report. Run deferred gates in the local checkout. Use `follow-up` for worker-owned gaps only.
