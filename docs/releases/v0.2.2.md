# Agent Task Bridge v0.2.2

Agent Task Bridge v0.2.2 adds a repo-local configuration file for host defaults. Protocol `1.0` and schema `1.1` stay in place. Capsules from v0.2.0 and v0.2.1 remain readable.

## Included

- Optional `.agent-task-bridge/config.json`, stored with the git-excluded bridge directory.
- `maxTokens` applies on export when `--max-tokens` is omitted.
- `validationPolicy` (`safe`, `prompt`, or `skip`) applies on import when `--validation-policy` is omitted.
- `extraHostOwnedSteps` is appended to the three default host gates when a delegation omits `host_owned_steps`.
- An explicit delegation `host_owned_steps` value, including `[]`, is left unchanged.
- Unknown keys, malformed JSON, and a symlinked config file fail the command.
- Privacy blocking, the 512 KB `REPORT.md` limit, and archive safety checks stay in code.

## Compatibility

A repository without the file keeps the v0.2.1 defaults. The config file is not embedded in the Task Capsule. Resolved host steps are still recorded on the exported manifest.

## Workflow

```json
{
  "maxTokens": 80000,
  "validationPolicy": "safe",
  "extraHostOwnedSteps": ["Release checklist sign-off"]
}
```

Copy [`examples/project-config.example.json`](../../examples/project-config.example.json) to `.agent-task-bridge/config.json`. Pass a CLI flag when one command should differ from the file.
