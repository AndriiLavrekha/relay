# Agent Task Bridge v0.3.3

Agent Task Bridge v0.3.3 fixes importing a reply copied from ChatGPT and adds an experimental, opt-in way to skip the copy-paste in Claude Code.

Protocol `1.0` and schema `1.1` are unchanged. Reported `bridge_version` and `exporter_version` are `0.3.3`.

## Fix

- **Import accepts ChatGPT's Copy-button text.** ChatGPT's Copy button returns Markdown-escaped text (`<<\<ATB_RESULT:…`, trailing backslashes, plain fences). `import` rejected it with `INVALID_RESULT_REPLY`. It now unescapes only the lines that begin with `<<<ATB_`, so file content is never altered.

## Experimental (Claude Code only)

- **`/task-bridge:delegate-chatgpt-browser`** drives your own logged-in Chrome through the Claude in Chrome extension: it uploads the capsule to chatgpt.com, sends the kickoff, copies the reply, and runs `import`.
- **Caution.** OpenAI's Terms of Use restrict automatically or programmatically extracting data or Output from its services, so this may violate them and can get an account warned or restricted. It is fragile and breaks when the ChatGPT interface changes. It runs only when you type the command, asks for an explicit yes every run, never logs in, and stops at a CAPTCHA, a usage limit, or any unexpected screen. The Codex plugin does not include it. The supported route is still the manual flow.
- When saving a copied reply from the Windows clipboard, write it as UTF-8; redirecting PowerShell output with `>` corrupts non-ASCII characters.

## Upgrading

Re-add the marketplace with `--ref v0.3.3` (Codex) or `/plugin marketplace add AndriiLavrekha/relay@v0.3.3` (Claude Code).
