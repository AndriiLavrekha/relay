# Agent Task Bridge v0.3.5

Agent Task Bridge v0.3.5 introduces local-only delegation cost and token usage tracking (`agent-task-bridge metrics` and a Claude Code `Stop` hook), adds a repository benchmark harness (`bench/`) for measuring delegation and tooling savings, and modernizes `README.md` for scanability and clarity.

Protocol `1.0` and schema `1.1` are unchanged. Reported `bridge_version` and `exporter_version` are `0.3.5`.

## Highlights

- **Delegation usage metrics (`agent-task-bridge metrics` & Claude Code `Stop` hook):**
  - New `metrics --repo .` CLI command (`src/metrics.mjs`) reads local Claude Code session transcripts, attributes Claude tokens and list-price USD cost per task ID across `plan`, `prep`, `export`, and `import` phases, and records capsule size, validation outcome, and ChatGPT wait time.
  - Persists an append-only ledger at `.agent-task-bridge/metrics.jsonl` (IDs, timestamps, and token counts only — no prompt or code content, no network or model calls) so metrics survive transcript pruning.
  - Supports `metrics note <task-id> --claude-estimate <usd>` to compute per-task saving percentages and custom model pricing via `metricsRates` in `.agent-task-bridge/config.json`.
  - Ships a `Stop` hook in the Claude Code plugin (`plugins/claude-code/hooks/hooks.json`) running `agent-task-bridge metrics --from-hook` after each turn (a no-op in repositories without exported tasks; never blocks or fails a session).
- **Benchmark harness (`bench/`, dev-only, excluded from npm package):**
  - Paired A/B harness (`bench/run.mjs`, `bench/report.mjs`) and ChatGPT delegation grading harness (`bench/chatgpt.mjs`, `bench/relay.mjs`) with hidden acceptance tests and measured baseline results in `bench/README.md`.
  - Scoped `npm test` in `package.json` to `node --test "test/**/*.test.mjs"` so intentionally failing `bench/` fixtures are not collected.
- **Documentation:**
  - Reorganized `README.md` for faster scanning across the 5-step workflow, install table, safety boundaries, CLI reference, and metrics usage.

## Installing or Upgrading to v0.3.5

- **Claude Code:**
  ```text
  /plugin marketplace add AndriiLavrekha/relay@v0.3.5
  /plugin install task-bridge@awesome-task-bridge
  ```
  *(If upgrading an existing installation to pick up the new `Stop` hook and `metrics` command, remove and re-add the marketplace at `@v0.3.5`, then run `claude plugin update task-bridge@awesome-task-bridge` or reinstall the plugin and restart your session.)*
- **Codex:**
  ```bash
  codex plugin remove task-bridge@awesome-task-bridge
  codex plugin marketplace remove awesome-task-bridge
  codex plugin marketplace add AndriiLavrekha/relay --ref v0.3.5
  codex plugin add task-bridge@awesome-task-bridge
  ```
- **Gemini CLI:**
  ```bash
  gemini extensions install https://github.com/AndriiLavrekha/relay --ref v0.3.5
  ```
- **Antigravity CLI / IDE:**
  ```bash
  agy plugin install https://github.com/AndriiLavrekha/relay/tree/v0.3.5/plugins/gemini
  ```
