# Relay v1.0.0

**Relay** (formerly *Agent Task Bridge*) is now ready for public release and distribution across **Claude Code**, **OpenAI Codex**, **Gemini CLI**, **Antigravity (`agy`)**, and **npm** (`@andriilavrekha/relay`).

## Highlights

- **Renamed to Relay:**
  - npm package & CLI: `@andriilavrekha/relay` and `relay` (`bin/relay.mjs`).
  - Marketplaces & plugins: `relay@relay` (Claude Code & OpenAI Codex) and `relay` (Gemini CLI & Antigravity), with Claude slash commands `/relay:plan-chatgpt`, `/relay:export-chatgpt`, `/relay:import-chatgpt`, and `/relay:delegate-chatgpt-browser`.
  - Local repository storage moved from `.agent-task-bridge/` to `.relay/` (automatically git-excluded in `.git/info/exclude`).
- **Seamless backwards compatibility:**
  - **Wire protocol v1.0 / schema 1.1 unchanged:** Existing Task Capsules (`atb_protocol: "1.0"`, `<<<ATB_*>>>`, `atb_...` task IDs) and Result Capsules continue to work without modification.
  - **Legacy storage fallback:** `loadStoredTask`, `listStoredTasks`, `findImportArtifacts`, `loadLifecycle`, `loadProjectConfig`, and `metrics` read `.relay/` first and automatically fall back to `.agent-task-bridge/` so in-progress tasks, configs, and metrics from `v0.3.x` remain usable.
  - **Reserved path protection:** Both `.relay` and `.agent-task-bridge` are blocked as unsafe paths on export/import and excluded from active-tree fingerprinting and dependency linking.
- **Configuration fix:**
  - Added `metricsRates` to `.relay/config.json` schema validation in `src/config.mjs` so configuring custom model pricing no longer causes `INVALID_PROJECT_CONFIG` errors during `export` or `import`.
- **Marketplace & public repository readiness:**
  - Added canonical brand icon [`assets/logo.svg`](../../assets/logo.svg), synced automatically to `plugins/codex/assets/logo.svg` and `plugins/gemini/assets/logo.svg` via `npm run bundle:plugins`.
  - Enriched Claude Code, Codex, and Gemini/Antigravity plugin and marketplace manifests with homepage, repository, license, keywords, category, and icon metadata.
  - Added cross-platform GitHub Actions CI (`.github/workflows/ci.yml`), issue/PR templates, [`CONTRIBUTING.md`](../../CONTRIBUTING.md), [`SECURITY.md`](../../SECURITY.md), [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md), and [`CHANGELOG.md`](../../CHANGELOG.md).
  - Added [`docs/user-guide.md`](../user-guide.md) and [`docs/marketplace-publishing.md`](../marketplace-publishing.md).
  - Removed internal `project-progress/` tracking files from git tracking so personal session notes are not published.

## Upgrading from `v0.3.x` (`task-bridge@awesome-task-bridge`)

```bash
# Claude Code
claude plugin uninstall task-bridge@awesome-task-bridge
claude plugin marketplace remove awesome-task-bridge
claude plugin marketplace add AndriiLavrekha/relay@v1.0.0
claude plugin install relay@relay

# OpenAI Codex
codex plugin remove task-bridge@awesome-task-bridge
codex plugin marketplace remove awesome-task-bridge
codex plugin marketplace add AndriiLavrekha/relay --ref v1.0.0
codex plugin add relay@relay

# Gemini CLI
gemini extensions uninstall task-bridge
gemini extensions install https://github.com/AndriiLavrekha/relay --ref v1.0.0

# Antigravity CLI
agy plugin uninstall task-bridge
agy plugin install https://github.com/AndriiLavrekha/relay/tree/v1.0.0/plugins/gemini
```
