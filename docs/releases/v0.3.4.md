# Agent Task Bridge v0.3.4

Agent Task Bridge v0.3.4 adds first-class **Gemini** host-agent support (Gemini CLI and Antigravity CLI/IDE) and introduces the **`plan-chatgpt`** task-breakdown and seam-planning skill across all three supported coding agents (Claude Code, OpenAI Codex, and Gemini).

Protocol `1.0` and schema `1.1` are unchanged. Reported `bridge_version` and `exporter_version` are `0.3.4`.

## Highlights

- **Gemini host-agent plugin (`plugins/gemini/` and root Gemini CLI extension):**
  - **Gemini CLI (`gemini extensions`):** Ships `gemini-extension.json`, `/plan-chatgpt`, `/export-chatgpt`, and `/import-chatgpt` slash commands (`commands/*.toml`), and bundle-synced `skills/` so `gemini extensions install https://github.com/AndriiLavrekha/relay` and `gemini extensions link .` work directly from the repository root or `plugins/gemini`.
  - **Antigravity CLI & IDE (`agy plugin`):** Ships `plugins/gemini/.gemini-plugin/plugin.json` (`agy plugin validate --strict plugins/gemini` passes with 0 errors and 0 warnings) and scoped workspace discovery in `.agents/plugins.json` (`"include_only": ["gemini"]`).
  - **Self-contained runtime:** `npm run bundle:plugins` populates `plugins/gemini/runtime/` alongside `claude-code` and `codex`, and `npm run smoke` verifies cross-provider round-trip execution (`gemini -> ChatGPT -> claude-code`) with `--source-agent gemini`.
- **`plan-chatgpt` skill across Claude Code, Codex, and Gemini:**
  - Guides the local coding agent to inspect the repository, decompose a feature or multi-part task along clean module seams into local host-owned wiring versus bounded exportable units for ChatGPT, draft the delegation contract (`editable_scope`, `files` by role, `acceptance_criteria`, `host_owned_steps`, parallel/sequential ordering), propose the **seam commit** first, and wait for developer confirmation before exporting.

## Installing or Upgrading to v0.3.4

- **Claude Code:**
  ```text
  /plugin marketplace add AndriiLavrekha/relay@v0.3.4
  /plugin install task-bridge@awesome-task-bridge
  ```
- **Codex:**
  ```bash
  codex plugin remove task-bridge@awesome-task-bridge
  codex plugin marketplace remove awesome-task-bridge
  codex plugin marketplace add AndriiLavrekha/relay --ref v0.3.4
  codex plugin add task-bridge@awesome-task-bridge
  ```
- **Gemini CLI:**
  ```bash
  gemini extensions install https://github.com/AndriiLavrekha/relay --ref v0.3.4
  ```
- **Antigravity CLI / IDE:**
  ```bash
  agy plugin install https://github.com/AndriiLavrekha/relay/tree/v0.3.4/plugins/gemini
  ```
