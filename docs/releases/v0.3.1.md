# Agent Task Bridge v0.3.1

Agent Task Bridge v0.3.1 fixes two problems found in the first live ChatGPT round trip.

Protocol `1.0` and schema `1.1` are unchanged. Reported `bridge_version` and `exporter_version` are `0.3.1`.

## Fixes

- **Kickoff prompt names the uploaded file.** `kickoff.md` now says ``Execute Task Capsule `task.md` ``, not the absolute local path. ChatGPT only sees the uploaded file, so a local path meant nothing to it. Kickoff files exported earlier keep the old path; re-export to refresh them.
- **Validation output is no longer cut off.** Output captured after the first chunk of a validation command was dropped and flagged as truncated, so import reports lost build and test diagnostics. Output is now kept up to the configured cap.
- **Timeout hint.** A timed-out validation command now points to `validationTimeoutMs` and `validationCommands` in `.agent-task-bridge/config.json`.

## Upgrading

Re-add the marketplace with `--ref v0.3.1` (Codex) or `/plugin marketplace add AndriiLavrekha/relay@v0.3.1` (Claude Code).
