# Agent Task Bridge v0.3.2

Agent Task Bridge v0.3.2 reduces type errors and failing tests in returned work, and stops an agent from integrating before it has read the staged validation.

Protocol `1.0` and schema `1.1` are unchanged. Reported `bridge_version` and `exporter_version` are `0.3.2`.

## Changes

- **Static self-review rule.** The capsule's Integration Contract now tells ChatGPT to check by reading what it cannot execute: narrow optional values, match the `contract` types exactly, and trace each new test through its code. The checks go under Validation claims in `REPORT.md`, separate from anything it ran. ChatGPT's sandbox has no access to your project toolchain, so this replaces "run the tests" where running is impossible.
- **Tooling in the Project Fingerprint.** TypeScript projects now report strictness options (`strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, and others, resolved through relative `extends` chains) and the declared versions of typescript, vitest, jest, eslint, and prettier.
- **Skills.** The export skill asks the agent to embed the type definitions the editable files read or write. The import skill (Claude Code and Codex) now requires reading staged validation before `integrate`, and sends failures to `follow-up` instead.

## Upgrading

Re-add the marketplace with `--ref v0.3.2` (Codex) or `/plugin marketplace add AndriiLavrekha/relay@v0.3.2` (Claude Code).
