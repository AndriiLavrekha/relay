# Agent Task Bridge v0.2.3

Agent Task Bridge v0.2.3 publishes five approved specifications. Protocol `1.0` and schema `1.1` stay in place. Export and import behavior matches v0.2.2. Reported `bridge_version` and `exporter_version` are `0.2.3`.

## Included

- [Live Codex and ChatGPT round trip](../superpowers/specs/2026-09-29-live-codex-chatgpt-round-trip-design.md). An operator procedure for published v0.2.2. No product change.
- [Related-file suggestions at export](../superpowers/specs/2026-09-29-related-file-suggestions-design.md).
- [OS isolation for validation commands](../superpowers/specs/2026-09-29-validation-os-sandbox-design.md).
- [Windows symlink tests in CI](../superpowers/specs/2026-09-29-windows-symlink-ci-design.md).
- [`handoff show` and `handoff check`](../superpowers/specs/2026-09-29-handoff-command-design.md).

## Not in this tag

The five items above are specified and not implemented. Capsules from v0.2.0, v0.2.1, and v0.2.2 remain readable. A repository without `.agent-task-bridge/config.json` keeps the v0.2.2 defaults.
