# Agent Task Bridge v0.2 Privacy and Result Integrity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scan all exported and returned capsule content, enforce additive Result Capsule integrity metadata, and turn worker completeness claims into explicit local evidence.

**Architecture:** Extend the existing secret scanner into a policy-driven privacy service that can scan text, paths, manifest metadata, and returned bytes with source labels. Keep archive parsing in `src/zip.mjs`, Result Capsule shape validation in `src/result-capsule.mjs`, and acceptance/evidence derivation in a focused `src/evidence.mjs` module consumed by the importer and review report.

**Tech Stack:** Node.js 22+ native ESM, Node `crypto`, `fs/promises`, built-in `node:test`, existing ZIP reader and YAML subset parser.

## Global Constraints

- Keep `atb_protocol: "1.0"`; add `schema_version: "1.1"` without a protocol cutover.
- High-confidence secrets block by default; warnings require explicit confirmation and are recorded.
- Never redact returned source code in place; metadata-only redaction is allowed.
- Worker status, model, tests, and token usage are untrusted claims.
- Hash raw returned file payload bytes before UTF-8 decoding.
- Research and non-complete code results require structurally valid `REPORT.md`.
- Preserve zero third-party runtime dependencies, native ESM, and generated provider bundles.

## File and interface map

- Modify `src/secrets.mjs`: text scanning, path scanning, pattern families, severity/action policy.
- Create `src/privacy.mjs`: finding model, policy evaluation, confirmation/allow recording, metadata-safe redaction.
- Modify `src/context.mjs`: use the shared scanner for selected context and expose file-level findings.
- Modify `src/exporter.mjs` and `src/task-capsule.mjs`: scan the final rendered capsule before storing it.
- Modify `src/result-capsule.mjs`: validate schema/status, per-file hashes/lengths, report headings, and legacy behavior.
- Create `src/evidence.mjs`: acceptance-criteria state and worker/local evidence separation.
- Modify `src/importer.mjs`: scan result content before staging and attach evidence to the import report.
- Modify `src/reporting.mjs`: render findings, integrity status, worker claims, and criteria states.
- Modify `protocol/TASK-CAPSULE-v1.md` and `protocol/RESULT-CAPSULE-v1.md`: document additive schema 1.1 fields.
- Create/modify `test/privacy.test.mjs`, `test/secrets.test.mjs`, `test/result-capsule.test.mjs`, `test/evidence.test.mjs`, and `test/e2e.test.mjs`.
