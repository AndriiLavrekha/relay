# Agent Task Bridge v0.2 Handoff and Review Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make incomplete external work recoverable through generated handoff artifacts, explicit lifecycle records, follow-up capsules, authoritative review output, immutable receipts, and confirmation-gated integration.

**Architecture:** Add focused `handoff`, `lifecycle`, `review`, and `receipts` modules. Keep durable records under `.agent-task-bridge/tasks/<task-id>/`, keep executable staging outside the repository, and make CLI commands read persisted records rather than recomputing undocumented state. Integration verifies the active-tree fingerprint and target `HEAD` before creating a branch worktree or applying reviewed changes.

**Tech Stack:** Node.js 22+ native ESM, JSON/Markdown artifacts, existing `src/storage.mjs`, Git worktree/diff commands, Node built-in `node:test`.

## Global Constraints

- Import/export remain active-worktree read-only until explicit integration confirmation.
- Result status is orthogonal to lifecycle; partial/blocked results may be staged and reviewed.
- Worker claims are displayed separately from local evidence.
- Receipts are immutable and never contain secret values or raw privacy matches.
- Generated output uses repository-relative paths and existing capsule contracts.
- Preserve zero third-party runtime dependencies, native ESM, Node.js 22+, and provider bundle synchronization.

## File and interface map

- Create `src/lifecycle.mjs`: valid lifecycle states, transitions, and persisted event records.
- Create `src/handoff.mjs`: kickoff prompt, checklist, expected contract, and summary artifacts.
- Create `src/review.mjs`: persisted import review, diff/stat, conflicts, validation, and evidence summary.
- Create `src/receipts.mjs`: immutable receipt creation and hash/provenance fields.
- Modify `src/storage.mjs`: task/import record discovery and safe artifact paths.
- Modify `src/exporter.mjs`: produce the handoff bundle and initial lifecycle record.
- Modify `src/importer.mjs`: transition lifecycle, write review inputs, and create receipts.
- Modify `src/reporting.mjs`: render task, import, review, and receipt summaries.
- Modify `bin/agent-task-bridge.mjs`: add `task show`, `review`, `follow-up`, and `integrate` command paths.
- Modify provider skill files under `plugins/claude-code/skills/` and `plugins/codex/skills/` after the CLI is stable.
- Create/modify `test/handoff.test.mjs`, `test/lifecycle.test.mjs`, `test/review.test.mjs`, `test/receipts.test.mjs`, `test/importer.test.mjs`, and `test/plugin-adapters.test.mjs`.

**Interfaces:**
- `LIFECYCLE_STATES = ['exported','result-received','inspected','staged','reviewed','integrated','rejected','failed','interrupted']`.
- `transitionLifecycle(record, nextState, details) -> updatedRecord`.
- `loadLifecycle(repoRoot, taskId, importId) -> record`.
- `writeLifecycle(repoRoot, record) -> lifecyclePath`.
- Valid transitions: exported -> result-received -> inspected -> staged -> reviewed -> integrated; inspected/staged/reviewed -> rejected|failed|interrupted is allowed only with an error detail; inspected/staged/reviewed -> follow-up is represented by a continuation record, not a replacement state.

  assert.equal(next.events.at(-1).resultStatus, 'partial');
});

test('transitionLifecycle rejects integrated before reviewed', () => {
  assert.throws(() => transitionLifecycle({ state: 'inspected', events: [] }, 'integrated'), /transition/i);
});
