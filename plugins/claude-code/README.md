# Relay for Claude Code

This directory is a self-contained Claude Code plugin. It contains the planning, export, and import skills (`plan-chatgpt`, `export-chatgpt`, `import-chatgpt`, and the opt-in `delegate-chatgpt-browser` skill) plus a generated copy of the deterministic Relay runtime, so Claude's plugin cache does not need files outside the installed plugin directory.

## Install

From Claude Code, add the `v1.0.0` marketplace release and install the plugin:

```text
/plugin marketplace add AndriiLavrekha/relay@v1.0.0
/plugin install relay@relay
```

Or from your terminal:

```bash
claude plugin marketplace add AndriiLavrekha/relay@v1.0.0
claude plugin install relay@relay
```

Run `/reload-plugins` if Claude asks you to reload.

The skills are namespaced by the plugin. Invoke `/relay:plan-chatgpt` to decompose a feature along clean seams, `/relay:export-chatgpt` to package a bounded unit, and `/relay:import-chatgpt` when a Result Capsule returns.

Relay requires **Node.js 22 or newer** and **Git**. It requires no OpenAI API key and no Anthropic API key.

## Upgrading from `v0.3.x` (`task-bridge@awesome-task-bridge`)

If you previously installed the pre-1.0 plugin under `task-bridge@awesome-task-bridge`, remove the old marketplace and install `relay@relay`. Existing `.agent-task-bridge/` tasks, configs, and metrics ledgers in your repositories continue to be read automatically by `.relay/`.

```bash
claude plugin uninstall task-bridge@awesome-task-bridge
claude plugin marketplace remove awesome-task-bridge
claude plugin marketplace add AndriiLavrekha/relay@v1.0.0
claude plugin install relay@relay
```

## Local development

For local development from a checkout, use:

```text
/plugin marketplace add /absolute/path/to/relay
/plugin install relay@relay
```

`runtime/` is generated by `npm run bundle:plugins`; do not edit the copied files directly. Make core changes under the repository `src/` or `bin/`, rebuild the provider bundles, and run `npm test`.

## Usage metrics

The plugin registers a `Stop` hook (`hooks/hooks.json`) that runs `relay.mjs metrics --from-hook` after each turn. It records the Claude tokens and cost spent by the export, import, and plan skills per task in `.relay/metrics.jsonl` (IDs, timestamps, and counts only — never prompts or code). It does nothing in a repository that has not exported a task, and it can never fail or block a session. Read the numbers with `node "${CLAUDE_PLUGIN_ROOT}/runtime/bin/relay.mjs" metrics --repo .`, and add `metrics note <task-id> --claude-estimate <usd>` to compare against what Claude would have spent doing the task itself.
