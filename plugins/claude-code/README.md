# Agent Task Bridge for Claude Code

This directory is a self-contained Claude Code plugin. It contains the planning/export/import skills (`plan-chatgpt`, `export-chatgpt`, `import-chatgpt`) and a generated copy of the deterministic Agent Task Bridge runtime, so Claude's plugin cache does not need files outside the installed plugin directory.

## Local installation from this repository

From Claude Code, add the `v0.3.4` release as a marketplace and install the plugin:

1. `/plugin marketplace add AndriiLavrekha/relay@v0.3.4`
2. `/plugin install task-bridge@awesome-task-bridge`
3. Run `/reload-plugins` if Claude asks you to reload.

The skills are namespaced by the plugin. Invoke `/task-bridge:plan-chatgpt` to decompose a feature along clean seams, `/task-bridge:export-chatgpt` to package a bounded unit, and `/task-bridge:import-chatgpt` when a Result Capsule returns.

The plugin requires Node.js 22 or newer and Git. It requires no OpenAI API key and no Anthropic API key.

For local development, use `/plugin marketplace add /absolute/path/to/agent-task-bridge` instead of the tagged marketplace.

`runtime/` is generated by `npm run bundle:plugins`; do not edit the copied files directly. Make core changes under the repository `src/` or `bin/`, rebuild the provider bundles, and run the test suite.

## Usage metrics

The plugin registers a `Stop` hook (`hooks/hooks.json`) that runs `agent-task-bridge metrics --from-hook` after each turn. It records the Claude tokens and cost spent by the export, import and plan skills per task in `.agent-task-bridge/metrics.jsonl` (ids, timestamps and counts only, never prompts or code). It does nothing in a repository that has not exported a task, and it can never fail or block a session. Read the numbers with `node "${CLAUDE_PLUGIN_ROOT}/runtime/bin/agent-task-bridge.mjs" metrics --repo .`, and add `metrics note <task-id> --claude-estimate <usd>` to compare against what Claude would have spent doing the task itself.
