# Relay for Gemini (Gemini CLI & Antigravity)

This directory is a self-contained Gemini plugin and extension bundle with `.gemini-plugin/plugin.json`, `gemini-extension.json`, planning/export/import skills (`plan-chatgpt`, `export-chatgpt`, `import-chatgpt`), and a generated copy of the deterministic Relay runtime.

## Install in Antigravity CLI / IDE (`agy`)

Install directly from the `plugins/gemini` subdirectory of the release or checkout:

```bash
agy plugin install https://github.com/AndriiLavrekha/relay/tree/v1.0.0/plugins/gemini
```

Or from a local checkout:

```bash
agy plugin install /absolute/path/to/relay/plugins/gemini
```

When you open a checkout of this repository directly in Antigravity, `.agents/plugins.json` automatically discovers `plugins/gemini` (`"include_only": ["gemini"]`).

## Install in Gemini CLI (`gemini`)

Install from the repository URL (or a local checkout):

```bash
gemini extensions install https://github.com/AndriiLavrekha/relay --ref v1.0.0
```

For local development from a checkout, link the repository root or `plugins/gemini`:

```bash
gemini extensions link /absolute/path/to/relay
# or:
gemini extensions link /absolute/path/to/relay/plugins/gemini
```

Restart your Gemini session after installing or updating.

## Upgrading from `v0.3.x` (`task-bridge`)

```bash
# Gemini CLI
gemini extensions uninstall task-bridge
gemini extensions install https://github.com/AndriiLavrekha/relay --ref v1.0.0

# Antigravity CLI
agy plugin uninstall task-bridge
agy plugin install https://github.com/AndriiLavrekha/relay/tree/v1.0.0/plugins/gemini
```

Existing `.agent-task-bridge/` tasks and configs in your repositories remain readable as a fallback under `.relay/`.

## Available skills and commands

- **`plan-chatgpt`** (`/plan-chatgpt` in Gemini CLI & Antigravity): Analyze a feature, split it along clean seams into local host-owned wiring and bounded exportable units, propose the seam commit, and draft delegation specs.
- **`export-chatgpt`** (`/export-chatgpt` in Gemini CLI & Antigravity): Export one bounded unit into a self-contained Task Capsule (`--source-agent gemini`).
- **`import-chatgpt`** (`/import-chatgpt` in Gemini CLI & Antigravity): Validate, drift-check, and stage a returned Result Capsule (`.zip` or `reply.md`) in an isolated Git worktree and review local validation evidence.

Relay requires **Node.js 22 or newer** and **Git**. It requires no OpenAI, Anthropic, or Gemini API key for the bridge runtime.

`runtime/` and `assets/` are generated by `npm run bundle:plugins`; change the canonical core in the repository root (`src/`, `bin/`, and `assets/`) and rebuild rather than editing bundled copies.
