# Relay for Codex

This directory is a self-contained Codex plugin bundle with `.codex-plugin/plugin.json`, planning/export/import skills (`plan-chatgpt`, `export-chatgpt`, `import-chatgpt`), and a generated copy of the deterministic Relay runtime.

## Install the v1.0.0 release

Add the GitHub marketplace pinned to the release tag, then install the plugin:

```bash
codex plugin marketplace add AndriiLavrekha/relay --ref v1.0.0
codex plugin add relay@relay
```

Start a new Codex session after installation.

## Upgrading to v1.0.0 (or from `task-bridge@awesome-task-bridge`)

`codex plugin marketplace upgrade` refreshes the currently configured Git ref; it does not change an existing marketplace pinned to an older release tag. Re-add the marketplace to move to a new release tag:

```bash
# If upgrading from pre-1.0 (task-bridge@awesome-task-bridge):
codex plugin remove task-bridge@awesome-task-bridge
codex plugin marketplace remove awesome-task-bridge

# Install or move to v1.0.0:
codex plugin marketplace add AndriiLavrekha/relay --ref v1.0.0
codex plugin add relay@relay
codex plugin list
```

Existing `.agent-task-bridge/` tasks and configs in your repositories are read automatically as a fallback. Use `--ref main` only when you explicitly want unreleased development code.

## Workspace-local installation

Add this repository as a local Codex marketplace, then install the plugin:

```bash
codex plugin marketplace add /absolute/path/to/relay
codex plugin list --available --marketplace relay
codex plugin add relay@relay
```

The marketplace catalog is `.agents/plugins/marketplace.json` and points to `./plugins/codex`. Restart Codex or refresh its plugin data after installation if the plugin is not immediately visible.

For another workspace, symlink or copy this directory to `<workspace>/plugins/codex` (or adjust the source path), then add the Relay entry to `<workspace>/.agents/plugins/marketplace.json`. For a user-wide local marketplace, place or symlink the plugin under `~/plugins/` and add an equivalent entry to `~/.agents/plugins/marketplace.json`.

Once installed, use Relay with prompts such as "Use plan-chatgpt to split this feature into exportable units," "Export this bounded task to ChatGPT," or "Import this ChatGPT Result Capsule and review it."

Relay requires **Node.js 22 or newer** and **Git**. It requires no OpenAI API key and no Anthropic API key.

`runtime/` and `assets/` are generated by `npm run bundle:plugins`; change the canonical core in the repository root and rebuild rather than editing bundled copies.
