# Agent Task Bridge for Codex

This directory is a self-contained Codex plugin bundle with `.codex-plugin/plugin.json`, export/import skills, and a generated copy of the deterministic bridge runtime.

## Install the v0.3.2 release

Add the GitHub marketplace pinned to the release tag, then install the plugin:

```text
codex plugin marketplace add AndriiLavrekha/relay --ref v0.3.2
codex plugin add task-bridge@awesome-task-bridge
```

Start a new Codex session after installation.

## Upgrade to the latest stable release

The [latest stable release](https://github.com/AndriiLavrekha/relay/releases/latest) is
`v0.3.2`:

```text
codex plugin remove task-bridge@awesome-task-bridge
codex plugin marketplace remove awesome-task-bridge
codex plugin marketplace add AndriiLavrekha/relay --ref v0.3.2
codex plugin add task-bridge@awesome-task-bridge
codex plugin list
```

`codex plugin marketplace upgrade` refreshes the currently configured Git ref; it does not change
an existing marketplace pinned to an older release tag. Use `--ref main` only when you explicitly
want unreleased development code.

## Workspace-local installation

Add this repository as a local Codex marketplace, then install the plugin:

```text
codex plugin marketplace add /absolute/path/to/agent-task-bridge
codex plugin list --available --marketplace awesome-task-bridge
codex plugin add task-bridge@awesome-task-bridge
```

The marketplace file is `.agents/plugins/marketplace.json` and points to `./plugins/codex`. Restart Codex or refresh its plugin data after installation if the plugin is not immediately visible.

For another workspace, symlink or copy this directory to `<workspace>/plugins/codex` (or adjust the source path), then add the Agent Task Bridge entry to `<workspace>/.agents/plugins/marketplace.json`. For a user-wide local marketplace, place/symlink the plugin under `~/plugins/` and add an equivalent entry to `~/.agents/plugins/marketplace.json`.

Once installed, use the Agent Task Bridge plugin/skills with prompts such as “Export this bounded task to ChatGPT” or “Import this ChatGPT Result Capsule and review it.”

The plugin requires Node.js 22 or newer and Git. It requires no OpenAI API key and no Anthropic API key.

`runtime/` is generated by `npm run bundle:plugins`; change the canonical core in the repository root and rebuild rather than editing bundled copies.
